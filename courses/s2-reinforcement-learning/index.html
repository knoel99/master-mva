0. Review: finite Markov decision processes

Discounted dynamic programming on a finite set is a contraction. Value iteration, policy iteration, and the sample-based methods of later chapters all chase that fixed point. This review names the objects and proves the contraction.

The running example has two rooms. State 0 pays reward 1 and moves to state 0 or state 1 with equal probability. State 1 pays reward 0 and moves in the same way. The discount is 1/2. With one action, the process is a Markov chain. A second action appears in ch. 2.

With one action the two-room process is a Markov chain. Its unique stationary law puts mass 1/2 on each state. Chapter 6 uses that fact for the gain.

Definition 0.1 — Finite MDP

A finite Markov decision process has a finite state set, a finite action set, a transition law, a reward, and a discount. For each state and each action the transition law is a probability distribution on the states. The reward is a real number, and it is deterministic given the pair. The discount lies in the half-open unit interval.

A policy \pi assigns to each state a distribution over actions. The value V^{\pi}(s) is the expected discounted return from s under \pi. The action value Q^{\pi}(s, a) is the same expectation when the first action is forced to equal a.

The Bellman expectation operator averages one backup under \pi.

(T^{\pi} v)(s) = \sum_a \pi(a \mid s) \Bigl( r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, v(s') \Bigr).

The optimality operator T^{\star} replaces the average over actions by a maximum. A policy is greedy for a vector v when, at every state, it puts mass only on actions that attain the maximum.

Theorem 0.1 — Bellman operators contract

For every policy \pi, and for the optimality operator, the sup-norm distance shrinks by at most \gamma.

\|T^{\pi} v - T^{\pi} w\|_{\infty} \le \gamma \, \|v - w\|_{\infty}.

The same bound holds with T^{\star} in place of T^{\pi}.

Proof.

  1. Expand one state of T^{\pi} v - T^{\pi} w. The rewards cancel. What remains is \gamma times an average of the differences v(s') - w(s').
  2. Every difference v(s') - w(s') has absolute value at most the sup norm of v - w. An average cannot exceed that bound. Multiply by \gamma.
  3. For the optimality operator, take an action that attains the maximum for the first vector. Its backup equals that operator applied to the first vector, and it lower-bounds the operator on the second vector. The gap is again at most the discount times the sup norm. Swap the two vectors.
  4. The sup norm is the maximum of the absolute state-wise gaps, so both operators are \gamma-contractions.

∎

The set of real vectors on a finite S, with the sup norm, is a complete metric space. Banach’s fixed-point theorem therefore gives each contraction a unique fixed point, and the iterates converge to it from every start. The fixed point of T^{\pi} is V^{\pi}. The fixed point of T^{\star} is the optimal value V^{\star}. A greedy policy for V^{\star} is optimal.

Key 0.2 — Value-iteration error

From any start V_0, the iterates V_{k+1} = T^{\star} V_k satisfy

\|V_k - V^{\star}\|_{\infty} \le \gamma^{k} \, \|V_0 - V^{\star}\|_{\infty}.

Example 0.3 — Two-room values

Write V(0) and V(1) for the unique fixed point of the two-room chain. The backup uses \gamma = 1/2 and the equal coin-flip transitions. Subtracting the two scalar equations gives V(0) - V(1) = 1. Substituting back gives

V(1) = \frac{1}{2}, \qquad V(0) = \frac{3}{2}.

Value iteration from the zero vector is a check. The first backup is the vector (1, 0). The second is (5/4, 1/4). The sup-norm distance to (3/2, 1/2) is 1/4. Theorem 0.1 allows up to 3/8. The observed error is smaller.

The backup above uses the model. Chapter 1 replaces it by a sample. An infinite state set, where a table is impossible, is ch. 4.

Key takeaways — chapter 0

  • A finite discounted MDP has Bellman operators T^{\pi} and T^{\star}, and both are \gamma-contractions in the sup norm.
  • Value iteration converges to V^{\star} at a geometric rate, from every initial vector.
  • On the two-room chain with discount 1/2, the values are 3/2 and 1/2.

1. Monte Carlo and temporal-difference learning

Value iteration reads P and r. Reinforcement learning does not. It sees a state, an action, and a reward, then a next state. This chapter replaces the backup by an average of samples.

Two averages are easy to confuse. Monte Carlo averages whole returns. Temporal difference averages a one-step target that still contains a current guess of the value. The second average is biased until the guess is right, and it usually has smaller variance.

Definition 1.1 — Return and TD target

The return G_t is the discounted sum of rewards from time t onward. An every-visit Monte Carlo estimate of V^{\pi}(s) averages G_t over the time indices at which the chain sits in s.

After a transition (s, a, r, s'), the TD target of a table V is r + \gamma V(s'). TD(0) moves the table toward that target with step size \alpha \in (0, 1].

Key 1.2 — TD(0) update

V(s) \leftarrow V(s) + \alpha \bigl( r + \gamma V(s') - V(s) \bigr).

Monte Carlo on a finite episode is unbiased for the value, once every episode is run to the end under the policy being evaluated. The price is the variance of a long sum.

TD substitutes the current guess at the next state for the random tail. A wrong guess biases the target. A noisy tail is exactly what the substitution removes. The two-room chain has no terminal time, so Exercise 2 cuts the return at a finite horizon and checks the missing tail.

SARSA and Q-learning store action values. SARSA bootstraps the next action that was actually drawn. Q-learning bootstraps the maximum over next actions, which is an off-policy target.

Proposition 1.3 — The expected TD target is a Bellman backup

Fix a table and a policy. Draw an action from the policy, then a next state from the transition law, and receive the deterministic reward of that pair. Given only the current state, the expected TD target equals the Bellman backup of the table.

Proof.

  1. Condition further on the action a. The reward equals r(s, a). The next state has law P(\cdot \mid s, a), so the expected bootstrap is r(s, a) plus \gamma times the corresponding average of V.
  2. Average that quantity over a drawn from \pi(\cdot \mid s). The result is the definition of (T^{\pi} V)(s) from ch. 0.

∎

Proposition 1.3 is not yet a convergence theorem. The noise of one transition has to be averaged. For each state the step sizes must sum to infinity, their squares must sum to a finite number, and the state must be visited forever.

Under those Robbins-Monro conditions, on-policy TD(0) converges to the value with probability 1. Jaakkola, Jordan, and Singh (1994) prove it. Q-learning needs the same discipline on every state-action pair. Watkins and Dayan (1992) prove convergence to the optimal action value. A constant step, as in Exercise 6, fails the square-sum test and only tracks a neighbourhood of the fixed point.

Example 1.4 — One TD step on the two-room chain

Start from the zero table, with \alpha = 1/2 and \gamma = 1/2. Observe state 0, reward 1, and next state 1. The TD target equals 1, because the value at state 1 is still 0. The update writes V(0) = 1/2.

The true value from Example 0.3 is 3/2. One step has closed one third of the error at state 0. The same transition, read as Q-learning with a zero table, writes Q(0, a) = 1/2. The maximum at the next state is 0, so the off-policy target and the on-policy target still agree. They separate as soon as the table is not flat.

Sampling the transition is enough to evaluate a fixed policy. Chapter 2 changes the policy. Chapter 3 replaces the table by a linear score.

Key takeaways — chapter 1

  • The expected TD target is the Bellman backup T^{\pi} V. Monte Carlo averages the return instead, with no bootstrap.
  • SARSA bootstraps the action that was taken. Q-learning bootstraps the greedy action of the current table.
  • With Robbins-Monro steps and infinite visits, tabular on-policy TD and Q-learning converge on a finite discounted MDP.

2. Policy iteration and the policy gradient

Chapter 0 improves a value by applying T^{\star}. An actor improves a policy. Policy iteration alternates a full evaluation with a greedy step. A policy gradient takes a small step in the parameters of a smooth policy \pi_{\theta}. The identity that justifies the step is already visible when there is only one state. The multi-state bookkeeping is cited after that proof.

Theorem 2.1 — Policy improvement

Let \pi and \pi' be two policies. Suppose that, at every state,

\sum_a \pi'(a \mid s)\, Q^{\pi}(s, a) \ge V^{\pi}(s).

Then V^{\pi'}(s) \ge V^{\pi}(s) at every state.

Proof.

  1. The hypothesis is the vector inequality V^{\pi} \le T^{\pi'} V^{\pi}. If v \le w entrywise, the same holds after T^{\pi'}, because a backup is an average of the next values with nonnegative weights that sum to 1, plus a reward that does not depend on the vector.
  2. Apply that monotonicity k times. Then V^{\pi} \le (T^{\pi'})^{k} V^{\pi}.
  3. The operator T^{\pi'} is a \gamma-contraction by Theorem 0.1, so the right-hand side converges to V^{\pi'}. The inequality passes to the limit.

∎

On a finite action set there are finitely many deterministic policies, so a strict improvement cannot cycle. Policy iteration therefore stops. Howard (1960) introduced the alternation. When the model is known, the evaluation step is the fixed point from ch. 0. When it is not, the evaluation step is ch. 1.

Example 2.2 — One improvement on the two-room MDP

Keep the two-room transitions of action a. Add action b, available in state 0. Action b pays reward 2 and moves to state 1 with probability 1. State 1 still has only action a.

Start from the policy that always selects a. Example 0.3 gives V(0) = 3/2 and V(1) = 1/2. The action value of b under this policy is

Q(0, b) = 2 + \gamma V(1) = 2 + \tfrac{1}{2} \cdot \tfrac{1}{2} = \tfrac{9}{4}.

Since 9/4 > 3/2, Theorem 2.1 says the policy that selects b in state 0 is at least as good. Solving its Bellman equation yields V(0) = 12/5 and V(1) = 4/5.

Under those new values, action a in state 0 scores 9/5, which is below 12/5. The greedy policy does not move again. One improvement was enough.

A parameterized actor is needed when the action set is too large to store. The continuum case is ch. 4. The derivative below has one state, so the occupancy measure does not appear.

Definition 2.3 — One-state objective

Suppose there is one state and finitely many actions. Action a has mean reward q(a). A policy \pi_{\theta} is positive and differentiable in \theta. The objective is the mean reward

J(\theta) = \sum_a \pi_{\theta}(a)\, q(a).

Theorem 2.4 — One-state policy gradient

\nabla J(\theta) = \sum_a \pi_{\theta}(a)\, \nabla \log \pi_{\theta}(a)\, q(a).

If a baseline b does not depend on the action, replacing q(a) by q(a) - b does not change the gradient.

Proof.

  1. Differentiate the finite sum that defines J. The derivative passes inside because the sum is finite and \pi_{\theta} is differentiable. You obtain \sum_a \nabla \pi_{\theta}(a)\, q(a).
  2. Wherever the action probability is positive, its gradient equals the probability times the gradient of its logarithm. Substitute that identity.
  3. The sum of those probability gradients equals the gradient of 1, which is zero. Multiplying by a baseline that ignores the action still gives zero.

∎

Key 2.5 — Score function

The gradient is an expectation of the score \nabla \log \pi_{\theta}(a) times the mean reward. A state-dependent baseline cancels for the same reason the constant b cancels. The score of a distribution always has mean zero.

Take two actions with means 1 and 0, and a logistic policy at parameter 0. Each action then has probability 1/2. The closed form of the derivative equals 1/4. The expected score times the mean reward equals the same 1/4. Theorem 2.4 is an identity in this one-state case, not an approximation.

Sutton, McAllester, Singh, and Mansour (1999) replace the mean reward by the action value and average over the discounted occupancy. Williams (1992) uses the random return instead. That Monte Carlo gradient is REINFORCE. A baseline that depends on the state but not on the action stays unbiased, by the same cancellation inside each state. Kakade (2001) replaces the Euclidean step by a Fisher-geometry step.

Key takeaways — chapter 2

  • If a new policy puts its mass on better action values of the old policy, its value is at least as high, at every state.
  • On a finite action set, exact policy iteration stops after finitely many greedy improvements.
  • In the one-state case, \nabla J is the expected score times the reward, and a baseline that ignores the action does not change it.

3. Linear function approximation

A table cannot store a value at every state of a large MDP. A critic stores a vector w and predicts a linear score. The questions are which w temporal-difference learning finds, and when the same update diverges.

Definition 3.1 — Linear critic

Let \phi(s) be a feature vector of fixed length, chosen in advance. The critic predicts V_w(s) = \phi(s)^{\top} w. The feature matrix \Phi has one row \phi(s)^{\top} per state. Assume the columns of \Phi are linearly independent.

Let d^{\pi} be the stationary distribution of an irreducible policy, and let D be the diagonal matrix of those masses. The projection \Pi is the orthogonal projection onto the column space of \Phi for the inner product weighted by D.

The vector of linear predictions is \Phi w. It cannot represent every table. The projected Bellman equation asks for the linear vector that reproduces itself after a backup and a projection.

\Phi w = \Pi\, T^{\pi} \Phi w.

The norm that matches D is \|u\|_{D}^{2} = \sum_s d^{\pi}(s)\, u(s)^{2}. It is a true norm when every stationary mass is positive, which is the irreducible case.

Proposition 3.2 — Projected backup contracts

Under the stationary law of the policy being evaluated, \Pi T^{\pi} is a \gamma-contraction for \|\cdot\|_{D}. In particular the projected equation has a unique solution w.

Proof.

  1. For any vector u, Jensen’s inequality at each state gives (P^{\pi} u)(s)^{2} \le (P^{\pi} u^{2})(s). Here P^{\pi} is the transition matrix of the policy.
  2. Sum against d^{\pi}. Stationarity says d^{\pi} is unchanged by P^{\pi}, so \|P^{\pi} u\|_{D} \le \|u\|_{D}.
  3. The rewards cancel in a difference of backups, and a factor \gamma remains. Therefore T^{\pi} itself is a \gamma-contraction in this norm.
  4. Orthogonal projection onto a subspace is non-expansive for the inner product that defines it. Compose the two maps. The composition \Pi T^{\pi} is a \gamma-contraction, so it has a unique fixed point.

∎

On-policy linear TD uses samples from \pi and the semi-gradient of the squared TD error, treating the bootstrap target as constant when differentiating. Its expected update is a step toward the fixed point of \Pi T^{\pi}. With Robbins-Monro step sizes, the weights converge to that unique w. Tsitsiklis and Van Roy (1997) prove the stochastic half of this statement. Proposition 3.2 is the contraction half.

Off policy, the weighting matrix is not the stationary law of the target policy. Step 2 of the proof used that match. Without it the projected backup can expand distances, and the weights can diverge. Baird (1995) gives a finite linear example. Sutton and Barto (2018) call the mix the deadly triad: function approximation, bootstrapping, and off-policy targets. Drop any one and that counterexample disappears.

Least-squares TD solves the projected equation in one linear system. Lagoudakis and Parr (2003) wrap that critic in policy iteration. An off-policy design matrix brings the same divergence back in algebraic form. A neural feature map also leaves Proposition 3.2, because the projection was onto a fixed subspace. Chapter 4 treats the practical controls, not a new contraction.

Exercise 6 is the sanity check. One-hot features make the projection the identity, so the fixed point is the true table, with entries 3/2 and 1/2.

Key takeaways — chapter 3

  • Linear on-policy TD converges to the unique solution of the projected Bellman equation, under the stationary weighting of \pi.
  • The proof needs Jensen’s inequality, stationarity of d^{\pi}, and the fact that a projection does not increase the D-norm.
  • Function approximation, bootstrapping, and off-policy targets can diverge together. Baird’s example is the standard finite witness.

4. Deep reinforcement learning and continuous actions

Lecture 5 leaves the linear critic. A network replaces \phi, and a continuous action replaces the finite max. The contraction of ch. 3 used a fixed subspace and the stationary law of one policy. Neither hypothesis survives here. The algorithms below are the ones the lecture title points toward. They are controlled modifications of updates you have already seen, not new fixed-point theorems.

Mnih, Kavukcuoglu, Silver, and coauthors (2015) train a network by a squared TD error. A replay buffer mixes past transitions. A target network, held fixed for many updates, supplies the bootstrap maximum.

Replay is off-policy, which is one corner of the deadly triad from ch. 3. The buffer and the target are engineering controls, not a contraction proof. van Hasselt, Guez, and Silver (2016) treat a second bias. The maximum of a noisy table is too high in expectation. Double Q-learning reads the bootstrap from the target network at the action chosen by the online network.

A continuous action set turns the maximum inside T^{\star} into an optimization over a subset of a Euclidean space. A table cannot list the actions. An actor \mu_{\phi}(s) proposes one.

Proposition 4.1 — One-state deterministic policy gradient

Fix a state s and a differentiable action map \mu_{\phi}(s). Let J(\phi) = Q(s, \mu_{\phi}(s)), and assume Q(s, \cdot) is differentiable. Then

\nabla_{\phi} J(\phi) = \nabla_{a} Q(s, a)\big|_{a = \mu_{\phi}(s)} \; \nabla_{\phi} \mu_{\phi}(s).

Proof. Apply the chain rule to the composition Q(s, \mu_{\phi}(s)). The state is held fixed, so the only dependence on \phi is through the action. The Jacobian of Q with respect to the action multiplies the Jacobian of \mu_{\phi}.

∎

Silver, Lever, Heess, Degris, Wierstra, and Riedmiller (2014) extend Proposition 4.1 to an average over the occupancy of the actor. Lillicrap and coauthors (2016) put networks on both Q and \mu and add a replay buffer. That combination is DDPG. The chain rule is the part proved here. The occupancy extension is the paper.

A stochastic actor stays closer to Theorem 2.4. Schulman, Wolski, Dhariwal, Radford, and Klimov (2017) form a ratio \rho, the probability of the sampled action under the new policy divided by its probability under the policy that collected the batch. Let A be an advantage estimate, and let \varepsilon \in (0, 1). The clipped surrogate at that sample is the minimum of \rho A and \mathrm{clip}(\rho, 1-\varepsilon, 1+\varepsilon)\, A.

Example 4.2 — One clipped sample

Take \varepsilon = 0.2 and \rho = 1.5. The clip sends 1.5 to 1.2.

If A = 1, the two candidates are 1.5 and 1.2, and the minimum is 1.2. The surrogate refuses part of the gain from a large increase in the probability of a good action.

If A = -1, the two candidates are -1.5 and -1.2, and the minimum is -1.5. The clip does not improve the score of a large increase in the probability of a bad action. Exercise 7 repeats the arithmetic at \rho = 0.5.

Nothing here claims that DQN or PPO converges to an optimal policy. The proofs that do converge need a finite table, or the linear on-policy critic of Proposition 3.2. A continuous state space is the same obstacle. Chapter 0 does not apply verbatim, and a network is a practical substitute for the missing table.

Key takeaways — chapter 4

  • DQN bootstraps from a slowly updated target network and trains on minibatches drawn from a replay buffer.
  • For a deterministic actor and a differentiable critic, the chain rule gives the policy gradient at one state.
  • The PPO clip takes a minimum of the probability-ratio term and a version whose ratio is cut at 1 \pm \varepsilon.

5. Exploration and regret

A greedy actor stops testing an action once another action looks better. On a bandit, and on an MDP, that choice can have a linear cost. Exploration is the family of rules that keep testing, with a cost you can bound. This chapter measures the cost by regret and records the optimistic order proved for UCRL2.

Definition 5.1 — Regret

For an average-reward problem, write \rho^{\star} for the optimal gain. After T steps the regret is

R_T = T \rho^{\star} - \sum_{t=1}^{T} r_t .

In a finite-horizon episode the same idea compares the optimal expected return with the return that was collected. Linear regret means the missing reward per step stays bounded away from zero.

Proposition 5.2 — Fixed exploration pays a linear cost

Consider a two-arm bandit with gap \Delta > 0. The rule \varepsilon-greedy, with a constant \varepsilon \in (0, 1], pulls a uniform random arm with probability \varepsilon and otherwise pulls the empirical leader. After both arms have been tried once, every later round pulls the worse arm with probability at least \varepsilon/2. The expected regret therefore grows at least linearly in T.

Proof.

  1. On an explore round the worse arm is chosen with probability 1/2. Explore rounds occur with probability \varepsilon, independently of the past. The product \varepsilon/2 is a lower bound on the probability of pulling the worse arm, even in rounds where the leader is already correct.
  2. Each such pull contributes \Delta to the expected regret. Over T-2 rounds after the forced first pulls, the expected regret is at least (\varepsilon/2)\, \Delta\, (T-2).

∎

The bound does not use concentration. If the empirical leader is itself the worse arm, the regret is larger. The linear lower bound still holds. Decaying \varepsilon can change the rate. A constant does not.

Optimism replaces the forced random pull by a bonus. UCRL2, from Jaksch, Ortner, and Auer (2010), keeps a confidence set on transitions and mean rewards. Extended value iteration plans for the best model inside that set. The agent follows the plan, updates the counts, and rebuilds the set.

On a communicating finite MDP, the diameter D is finite. It is the maximum, over pairs of states, of the shortest expected travel time from one state to the other, where the minimum is over policies. Jaksch, Ortner, and Auer (2010) prove that, with probability at least 1-\delta, the regret of UCRL2 after T steps is of order

D S \sqrt{A T \log(T/\delta)} .

Here S and A are the numbers of states and actions. This page does not reproduce their leading constant. Quoting an order without the constant is a summary of their theorem, not a new proof.

The shape of the argument is not a complete proof. A concentration inequality keeps the true model inside the confidence set, except on an event of small probability. On the good event the optimistic gain is at least the optimal gain, because the truth is one legal model.

Steps where the counts are still small, or where the confidence set fails, are charged separately and produce the square root. The diameter turns a one-step error in the transition law into a bounded error in the gain. The algebra that makes this charging rigorous is the paper.

Posterior sampling draws one model from the posterior and plans for that draw (Osband, Russo, and Van Roy, 2013). The exploration is in the draw. On tabular MDPs the Bayesian regret is still of square-root order in the horizon.

If the MDP is not communicating, the diameter is infinite and the UCRL2 statement does not apply. Gap-dependent bounds are ch. 6. The one-state case is a bandit, and ch. 7 replaces the square root by a logarithm.

Key takeaways — chapter 5

  • With a constant exploration probability, expected regret on a two-arm bandit grows linearly in T.
  • UCRL2 plans in a confidence set. On a communicating MDP its regret is of order D S \sqrt{A T \log(T/\delta)} with high probability.
  • Posterior sampling draws a model and plans exactly for the draw. The exploration is in the draw.

6. Average reward and instance-dependent bounds

Discounting makes the distant future small. Many control problems do not come with a natural discount. The average reward per step replaces the discounted value. Instance-dependent analysis then tries to pay for the gap of this MDP, not only for the worst MDP of a given size.

Definition 6.1 — Gain, bias, and the Poisson equation

The gain \rho^{\pi} is the limit of the expected reward per step, when the limit exists. Under a unichain policy on a finite MDP the limit exists and does not depend on the start state. The bias h^{\pi}(s) is the transient advantage of starting from s. The pair solves

h(s) + \rho = r(s, \pi) + \sum_{s'} P(s' \mid s, \pi)\, h(s').

Proposition 6.2 — The bias is defined up to a constant

If (\rho, h) solves the Poisson equation, then so does (\rho, h+c) for every constant c. The gain does not change.

Proof. A transition matrix sends a constant function to itself, because each row sums to 1. Adding c to h therefore adds c to both sides of the equation. The two copies of c cancel, and \rho is untouched.

∎

Relative value iteration uses Proposition 6.2 in an algorithm. After each backup it subtracts the bias at a fixed reference state, which pins the additive constant. The backup itself is the right-hand side of the Poisson equation, with the unknown \rho represented by that subtraction rather than by a separate variable.

Example 6.3 — Gain of the two-room chain

Take only action a, with discount removed. From either start, one step already reaches the stationary law that puts mass 1/2 on each state. Rewards are 1 in state 0 and 0 in state 1, so

\rho = \frac{1}{2}.

Set h(1) = 0. The Poisson equation at state 0 becomes h(0) + 1/2 = 1 + h(0)/2, hence h(0) = 1. The equation at state 1 reads 1/2 on both sides. It checks.

Now offer action b in state 0, paying 2 and moving to state 1 for sure. The stationary mass on state 0 falls to 1/3, because every visit to state 0 is followed by a visit to state 1, and state 1 returns to state 0 only half the time. The gain is 2/3. The random policy, with gain 1/2, is worse by 1/6. Exercise 9 lowers the reward of b from 2 to 1. The comparison reverses.

A diameter bound does not mention the gap of one sixth. Moving the reward of action b can change which policy is optimal, without changing the diameter or the number of states or actions. Burnetas and Katehakis (1997) prove an asymptotic lower bound that does see the gap. Consider algorithms whose regret grows slower than every positive power of the horizon, on every MDP in the class. Any such algorithm must satisfy

\liminf_{T \to \infty} \frac{R_T}{\log T} \ge c(M).

The constant c(M) is built from KL divergences between the optimal transition law and the laws of suboptimal actions, weighted by the gaps. An algorithm is instance-optimal in this asymptotic sense when its limsup matches c(M).

Simchowitz and Jamieson (2019) prove a non-asymptotic gap-dependent upper bound for episodic tabular MDPs. A finite-time match of the Burnetas-Katehakis constant for average reward is not a theorem of these notes. Chapter 8 records that gap.

When the discount is close to 1, the discounted value is about the gain divided by one minus the discount, plus a bounded bias. A small error in the gain becomes a large error in the value.

Key takeaways — chapter 6

  • The Poisson equation ties the gain \rho to a bias h that is unique only up to an additive constant.
  • On the two-room chain the random policy has gain 1/2. The action that pays 2 and leaves state 0 has gain 2/3.
  • Burnetas and Katehakis (1997) force \liminf R_T / \log T \ge c(M) on uniformly fast algorithms. The constant depends on the gaps.

7. Bandits, pure exploration, and planning

A bandit is an MDP with one state. Lecture 8 uses that case twice. Pure exploration asks for the best arm and then stops. Rewards collected before stopping do not enter the score. Planning with a generative model treats each decision node as a bandit over the branches that leave it.

Definition 7.1 — Regret and \delta-correct identification

A stochastic bandit has K arms with unknown mean rewards. A pull returns a reward in [0, 1]. The regret compares the collected rewards with T times the best mean.

Best-arm identification uses a different score. The agent picks a stopping time \tau and a guess of the best arm. The strategy is \delta-correct when, for every mean vector, the probability that the guess is wrong is at most \delta. The cost is the expected stopping time, not the regret.

Proposition 7.2 — UCB bonus threshold

Give each arm an index equal to its empirical mean plus the square-root bonus below. Once the pull count is at least eight times the log of the round, divided by the squared gap, the bonus is at most half the gap.

\sqrt{2 \ln t / n_i}.

Proof. Require \sqrt{2 \ln t / n} \le \Delta/2. Both sides are nonnegative. Square them. Then 2 \ln t / n \le \Delta^{2}/4, so n \ge 8 \ln t / \Delta^{2}.

∎

Auer, Cesa-Bianchi, and Fischer (2002), Theorem 1, turn the threshold into an expectation for the rule called UCB1. For every horizon T \ge 2,

\mathbb{E}[R_T] \le \sum_{i : \Delta_i > 0} \left( \frac{8 \ln T}{\Delta_i} + \left(1 + \frac{\pi^{2}}{3}\right) \Delta_i \right).

The proof in the paper sums the probabilities of the rounds where a suboptimal arm is pulled after its bonus has fallen below \Delta_i/2. Those rounds require a concentration failure. The series of failures produces the constant \pi^{2}/3. Proposition 7.2 is the threshold inside that argument. The series is theirs.

Cappé, Garivier, Maillard, Munos, and Stoltz (2013) replace the Hoeffding bonus by a Kullback-Leibler confidence bound. The logarithmic shape stays. The leading factor improves, because the divergence sees the two means and not only the range of the reward.

Example 7.3 — Greedy lock-in against UCB

Means 0.4 and 0.6, horizon 2000, three hundred seeds. The greedy rule tries each arm once and then stays with the empirical leader. UCB uses the bonus of Proposition 7.2. The script prints the mean regrets, the mean number of UCB pulls of the worse arm, the number of greedy seeds that finish on the worse arm, and the two sample standard deviations.

import numpy
means = numpy.array([0.4, 0.6])
T = 2000
n_seeds = 300

def greedy(rng):
    n = numpy.zeros(2)
    s = numpy.zeros(2)
    regret = 0.0
    for t in range(T):
        if t < 2:
            a = t
        else:
            a = int(numpy.argmax(s / numpy.maximum(n, 1.0)))
        x = float(rng.random() < means[a])
        n[a] = n[a] + 1.0
        s[a] = s[a] + x
        regret = regret + (0.6 - means[a])
    leader = int(numpy.argmax(s / n))
    return regret, leader

def ucb(rng):
    n = numpy.zeros(2)
    s = numpy.zeros(2)
    regret = 0.0
    for t in range(1, T + 1):
        if (n == 0).any():
            a = int(numpy.argmin(n))
        else:
            bonus = numpy.sqrt(2.0 * numpy.log(t) / n)
            a = int(numpy.argmax(s / n + bonus))
        x = float(rng.random() < means[a])
        n[a] = n[a] + 1.0
        s[a] = s[a] + x
        regret = regret + (0.6 - means[a])
    return regret, float(n[0])

g = numpy.zeros(n_seeds)
u = numpy.zeros(n_seeds)
bad = numpy.zeros(n_seeds)
locked = 0
for seed in range(n_seeds):
    g[seed], leader = greedy(numpy.random.default_rng(seed))
    u[seed], bad[seed] = ucb(numpy.random.default_rng(seed))
    if leader == 0:
        locked = locked + 1
print(round(float(g.mean()), 1))
print(round(float(u.mean()), 1))
print(round(float(bad.mean()), 1))
print(locked)
print(round(float(g.std(ddof=1)), 1))
print(round(float(u.std(ddof=1)), 1))

The script prints six numbers, in order. Mean greedy regret 170.4. Mean UCB regret 36.2. Mean UCB pulls of the worse arm 181.0. Greedy seeds that finish on the worse arm, 127. Sample standard deviations 197.1 and 9.8.

The greedy sample standard deviation is 197.1, so the mean 170.4 has a standard error near 11. UCB’s sample standard deviation is 9.8, so 36.2 is stable. The gap is the lock-in of Proposition 5.2. 127 of 300 greedy seeds finish on the worse arm. UCB still pulls that arm 181 times out of 2000. The bonus limits those pulls. It does not delete them.

Kaufmann, Cappé, and Garivier (2016) prove a lower bound for delta-correct identification. As the allowed error goes to zero, any such strategy needs an expected stopping time at least on the order of a complexity constant times the log of one over the error. That constant is the value of a finite convex program in the arm means. For a Gaussian gap it is of order one over the squared gap.

Garivier and Kaufmann (2016) match the lower bound with Track-and-Stop. Audibert, Bubeck, and Munos (2010) study the fixed-budget cousin, where the horizon is given and the error probability is what you drive down.

Hoeffding’s inequality is the elementary sufficient condition, and it is looser than the KL program. For a reward in [0, 1],

\mathbb{P}\bigl(|\hat\mu - \mu| \ge t\bigr) \le 2 \exp(-2 n t^{2}).

Set t = \Delta/2 on a two-arm problem, and take a union bound over the two arms. The probability that either interval fails is at most 4 \exp(-n \Delta^{2} / 2). Asking for this quantity to be at most \delta forces

n \ge \frac{2 \ln(4/\delta)}{\Delta^{2}}

samples on each arm, if both arms are sampled equally often. Exercise 10 evaluates the threshold. The count is sufficient for this test. It is not the minimal count allowed by the 2016 lower bound.

A generative model draws a next state from any pair (s, a) you name. Kearns, Mansour, and Ng (2002) build a sparse tree of depth H. The branching at a node depends on the accuracy and on the number of actions. It does not depend on the number of states. The number of samples grows exponentially with H.

Kocsis and Szepesvári (2006) grow the tree only along branches chosen by a UCB rule at each node. The algorithm is called UCT. Coquelin and Munos (2007) show that the worst-case cost can still be exponential in the depth, and that a uniform sparse sample can be the better worst-case rule.

Key takeaways — chapter 7

  • After 8 \ln t / \Delta^{2} pulls, the UCB bonus has fallen to at most \Delta/2. The regret bound of UCB1 is logarithmic in T.
  • Best-arm identification scores the stopping time of a \delta-correct guess. The KL lower bound of Kaufmann, Cappé, and Garivier (2016) is the benchmark.
  • Sparse sampling ignores the size of the state space and pays an exponential cost in the horizon. UCT grows the same kind of tree with a bandit rule at each node.

8. Research directions and open problems

The eight lectures close on tabular theory, with networks present as algorithms. The open problems below are places where a finite-time guarantee is missing, or where the guarantee needs an assumption the application does not give. The citations are to the papers named. They are not a claim about a research programme attached to the course.

Average-reward instance optimality is still split in two. Burnetas and Katehakis (1997) identify the asymptotic constant c(M). Jaksch, Ortner, and Auer (2010) give a square-root upper bound that does not depend on the gaps. A finite-time upper bound that matches c(M) \log T on communicating MDPs, with a remainder a student could plot, is a research target. Episodic gap-dependent bounds such as Simchowitz and Jamieson (2019) do not transfer by renaming \gamma. The gain is a limit, and the bias can be large when the mixing time is large.

Offline data change the exploration problem into a coverage problem. Jin, Yang, and Wang (2021) analyse pessimistic value iteration. When the logged policy already covers the actions an optimal policy would take, the pessimism penalty is enough for a finite-sample guarantee. The coverage coefficient can be arbitrarily large. Estimating it from the same log, and saying something useful when it is infinite, is open. Nothing in ch. 5 removes the need for coverage, because UCRL2 chooses the actions itself.

Distributional critics replace the expected backup by a backup on laws of the return. Bellemare, Dabney, and Munos (2017) prove that this distributional Bellman operator is a \gamma-contraction in a Wasserstein metric. The contraction explains why the fixed point exists. It does not say that a bonus built from the shape of the distribution improves the regret order of UCRL2. That implication is a conjecture one could try to make precise. It is not a theorem quoted here.

Tree search has the same split between practice and worst-case proof. UCT is the planning rule of lecture 8. Coquelin and Munos (2007) exhibit trees where uniform sparse sampling wins in the worst case. A planner that keeps a UCT bias on typical trees and a sparse-sampling worst-case bound at the same time is not on the syllabus.

Networks and optimism are taught in different chapters for a reason. Chapter 4 trains a network without a confidence set. Chapter 5 builds a confidence set for a table. A confidence set for a neural action-value function, sharp enough to recover a square-root regret when the MDP is tabular and the features contain the one-hot table, is open. Osband, Blundell, Pritzel, and Van Roy (2016) use a bootstrap ensemble as a practical substitute. Their guarantee is not the Jaksch-Ortner-Auer theorem.

Key takeaways — chapter 8

  • The asymptotic constant c(M) and the square-root upper bound are both known. A finite-time match of the constant, for average reward, is not.
  • Pessimistic offline evaluation needs a coverage condition. Distributional contraction in a Wasserstein metric does not by itself give a tighter regret bound.
  • UCT and neural critics are algorithms of the syllabus whose worst-case sample bounds are still research questions.

Exercises

  1. ★ Two-room fixed point. On the chain of Example 0.3, discount 1/2, reward 1 in state 0 and 0 in state 1, with equal probability of either next state, compute V(0) and V(1). From the zero vector, compute the second value-iteration backup.

    Solution. Subtracting the two Bellman equations yields V(0) - V(1) = 1, and then V(1) = 1/2, V(0) = 3/2. The first backup of zero is (1, 0). The second is (5/4, 1/4).

  2. ★ Monte Carlo return on the two-room chain. The fence cuts every episode at horizon 30 and averages 400 episodes from state 0. Run it. Compare the printed mean with 3/2.

    import numpy
rng = numpy.random.default_rng(0)
gamma = 0.5
H = 30
N = 400
G = numpy.zeros(N)
for n in range(N):
    s = 0
    g = 0.0
    disc = 1.0
    for t in range(H):
        if s == 0:
            r = 1.0
            s = 0 if rng.random() < 0.5 else 1
        else:
            r = 0.0
            s = 0 if rng.random() < 0.5 else 1
        g = g + disc * r
        disc = disc * gamma
    G[n] = g
print(round(float(G.mean()), 4))

    Solution. The fence prints 1.5073. The exact value is 1.5. The missing tail after 30 steps is at most 2 \cdot (1/2)^{30}, which is far below 10^{-8}. The gap 0.0073 is sampling noise at this seed, not truncation bias.

  3. ★ One Q-learning update. Start from a zero table, with \gamma = 1/2 and \alpha = 1/2. Observe state 0, action b, reward 2, and next state 1. Compute the new value of Q(0, b). Say why SARSA, taking next action a from the same zero table, writes the same number.

    Solution. The target is 2 + (1/2) \cdot 0 = 2. The update writes Q(0, b) = 1. SARSA reads Q(1, a) = 0, so its target is also 2. The two rules disagree only after some next-state entry becomes positive.

  4. ★ Read a greedy policy. Take Q(0, a) = 9/5, Q(0, b) = 12/5, and Q(1, a) = 4/5. Name the greedy action in each state, and match it with Example 2.2.

    Solution. The maximum in state 0 is 12/5, attained by action b. State 1 has only action a. This is the improved policy of Example 2.2, whose values are 12/5 and 4/5.

  5. ★★ Policy improvement with a check. Start from the always-a values V(0) = 3/2 and V(1) = 1/2. Action b pays 2 and moves from state 0 to state 1 for sure.

    Compute Q(0, b) under the old values. Solve the Bellman equation of the policy that switches state 0 to b. Under the new values, compute the action value of a in state 0, and say whether a further greedy step moves the policy.

    Solution. The old action value is 9/4, which is above 3/2, so Theorem 2.1 allows the switch. The new values are 12/5 and 4/5. Action a then scores 9/5, below 12/5, so the greedy policy stays.

  6. ★★ Constant-step TD, averaged. The fence runs TD(0) on the two-room chain with step size 0.05 for 10^{5} steps, and averages the table from step 20000 onward. Run it. Compare both printed numbers with 3/2 and 1/2.

    import numpy
rng = numpy.random.default_rng(0)
gamma = 0.5
alpha = 0.05
V = numpy.zeros(2)
s = 0
acc = numpy.zeros(2)
count = 0
for t in range(100000):
    if s == 0:
        r = 1.0
        sp = 0 if rng.random() < 0.5 else 1
    else:
        r = 0.0
        sp = 0 if rng.random() < 0.5 else 1
    V[s] = V[s] + alpha * (r + gamma * V[sp] - V[s])
    s = sp
    if t >= 20000:
        acc = acc + V
        count = count + 1
print(round(float(acc[0] / count), 4))
print(round(float(acc[1] / count), 4))

    Solution. The fence prints 1.4996 and 0.5047. The exact values are 1.5 and 0.5. A constant step does not meet the Robbins-Monro square-sum condition of ch. 1. The average of the late iterates is the right summary, and it lands within 0.005 of each coordinate.

  7. ★★ Clip a probability ratio. Take \varepsilon = 0.2 and \rho = 0.5. Compute the clipped surrogate for A = 1 and for A = -1. Say in which of the two cases the clip changes the value.

    Solution. The clip of 0.5 onto the window from 0.8 to 1.2 equals 0.8. For advantage 1, the minimum of 0.5 and 0.8 is 0.5. For advantage -1, the minimum of -0.5 and -0.8 is -0.8. The clip changes the value only in the second case.

  8. ★★ Two UCB indices. At a round where twice the log of the time equals 8, arm 1 has count 8 and mean 0.75, and arm 2 has count 32 and mean 0.5. Compute both indices and name the arm that is pulled. With the same log term, find the smallest count that brings the bonus of arm 1 down to 0.25.

    Solution. The bonuses are the square roots of 8/8 and 8/32, hence 1 and 1/2. The indices are 1.75 and 1.0, so arm 1 is pulled. The bonus falls to 1/4 once the count reaches 128.

  9. ★★★ A gain that loses. Keep the transitions of action b from Example 6.3, but pay reward 1 instead of 2. Compute the stationary mass on state 0, the gain, and the bias with h(1) = 0. Compare the gain with the random-policy gain 1/2.

    Explain, in terms of D, S, and A, why a diameter bound of the UCRL2 type does not see the difference between reward 1 and reward 2, while c(M) in ch. 6 does.

    Solution. The stationary mass on state 0 is still 1/3, so the gain is 1/3, and the bias at state 0 is 2/3 when the bias at state 1 is 0. The random policy, with gain 1/2, is better by 1/6. A bound that uses only the diameter and the sizes of the two sets does not depend on the reward of b, so it is silent when that reward moves from 1 to 2. The constant c(M) is built from the gaps, so it moves.

  10. ★★★ A Hoeffding stopping count. Rewards lie in [0, 1]. You sample two arms equally often. You want both empirical means to sit within \Delta/2 of the truth, with failure probability at most \delta after a union bound, using the Hoeffding inequality stated in ch. 7.

    Derive the sufficient count n on each arm. Evaluate it when \ln(4/\delta) = 8 and \Delta = 1/2. Say why this count can be larger than the KL benchmark of Kaufmann, Cappé, and Garivier (2016).

    Solution. The one-arm tail 2 \exp(-2 n t^{2}) at t = \Delta/2 equals 2 \exp(-n \Delta^{2}/2). Two arms cost a factor 2, hence 4 \exp(-n \Delta^{2}/2) \le \delta, so n \ge 2 \ln(4/\delta) / \Delta^{2}. The numbers give n \ge 64. Hoeffding uses only the range. The KL program uses the two laws, and its leading factor is never worse.
