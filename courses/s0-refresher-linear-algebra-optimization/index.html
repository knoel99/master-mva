0. Review: norms, inner products and symmetric matrices

Semester 1 asks you to compare vectors and to read the curvature of a quadratic. Both jobs use an inner product. A Hessian or a Gram matrix is symmetric, so its eigenvalues are real, and those eigenvalues are the curvatures of ch. 2.

Inner product and norm

Definition 0.1 — Euclidean inner product

For x, y \in \mathbb{R}^n the Euclidean inner product and the Euclidean norm are \langle x, y \rangle = x^\top y, \qquad \|x\|_2 = \sqrt{x^\top x}. The norm vanishes only at x = 0. Scaling x by a real number t scales the norm by |t|.

Proposition 0.2 — Cauchy-Schwarz

For all x, y \in \mathbb{R}^n, |\langle x, y \rangle| \le \|x\|_2 \, \|y\|_2. Equality holds if and only if one vector is a scalar multiple of the other.

Proof. If y = 0, both sides are zero.

If y \neq 0, the square \|x - t y\|_2^2 is nonnegative for every real t. Choose the scalar t = \frac{\langle x, y \rangle}{\|y\|_2^2}. Expanding the square leaves \|x\|_2^2 \, \|y\|_2^2 - \langle x, y \rangle^2 \ge 0.

Equality holds precisely when x - t y = 0, so x is a multiple of y. The case x = 0 is the same argument with the roles swapped. ∎

Three norms

Definition 0.3 — The 1-norm and the infinity norm

On \mathbb{R}^n, \|x\|_1 = \sum_{i=1}^n |x_i|, \qquad \|x\|_\infty = \max_i |x_i|.

Example 0.4 — The vector (3, -4)

For v = (3, -4) one has \|v\|_1 = 7, \|v\|_2 = 5 and \|v\|_\infty = 4. Thus 4 \le 5 \le 7.

On \mathbb{R}^n the same order holds for every x. Cauchy-Schwarz on the vector of absolute values and the vector of ones also gives \|x\|_1 \le \sqrt{n}\,\|x\|_2. Exercise 1 checks both comparisons on v.

Symmetric matrices

Definition 0.5 — Eigenvalue

A real number \lambda is an eigenvalue of a square matrix A when A q = \lambda q for a nonzero vector q. That vector is an eigenvector.

The matrix A is symmetric when A^\top = A.

Theorem 0.6 — Spectral theorem

Let A \in \mathbb{R}^{n \times n} be symmetric. Then A has an orthonormal basis of eigenvectors. Equivalently, there exist an orthogonal matrix Q and a real diagonal matrix D such that A = Q D Q^\top.

Proof. The claim is immediate for n = 1. Assume it in dimension n - 1.

The unit sphere is compact and x \mapsto x^\top A x is continuous, so the maximum is attained at some unit vector q.

Take any v with v^\top q = 0. For small t, the vector q + t v is nonzero. Normalizing it keeps that vector on the sphere.

The derivative of the quadratic form at t = 0 must vanish. Symmetry makes that derivative equal to 2 v^\top A q.

Hence v^\top A q = 0 for every such v, so A q is parallel to q.

The eigenvalue \lambda = q^\top A q is real. If v^\top q = 0, then (A v)^\top q = v^\top A q = 0, so the orthogonal complement of q is invariant. The restriction of A to that complement is symmetric of size n - 1. Induction supplies the remaining orthonormal eigenvectors. ∎

Exercise 3 checks the factorization on a 2 by 2 matrix. There the characteristic polynomial is enough, and the induction is unnecessary.

Example 0.7 — A 2 by 2 factorization

Take A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}. The characteristic polynomial is (\lambda - 1)(\lambda - 3). Unit eigenvectors for the eigenvalues 3 and 1 are (1, 1)/\sqrt{2} and (1, -1)/\sqrt{2}.

Stacking them as the columns of Q, with the eigenvalues on the diagonal of D, recovers A.

For the first canonical vector, e_1^\top A e_1 = 2, which lies between the eigenvalues 1 and 3.

import numpy
A = numpy.array([[2.0, 1.0], [1.0, 2.0]])
s = numpy.sqrt(2.0)
Q = numpy.array([[1.0, 1.0], [1.0, -1.0]]) / s
D = numpy.diag([3.0, 1.0])
err = numpy.max(numpy.abs(Q @ D @ Q.T - A))
print(f"{err:.1e}")

The reconstruction error prints as 4.4e-16, which is rounding error, not a gap in the factorization.

Key 0.8 — Rayleigh quotient

If A is symmetric with least eigenvalue \lambda_{\min} and greatest eigenvalue \lambda_{\max}, every nonzero x satisfies \lambda_{\min} \le \frac{x^\top A x}{x^\top x} \le \lambda_{\max}. Both ends are attained at the corresponding eigenvectors.

Write x = Q c with the orthogonal factor from Theorem 0.6. Then x^\top A x equals \sum_i \lambda_i c_i^2, and x^\top x equals \sum_i c_i^2.

The quotient is a weighted average of the eigenvalues, so it lies between the extreme ones. ch. 2 reads those extremes as the curvature bounds L and \mu.

Key takeaways — chapter 0

  • The Euclidean norm comes from the inner product, and Cauchy-Schwarz bounds every coordinate.
  • The infinity norm, the Euclidean norm and the 1-norm increase in that order.
  • A real symmetric matrix has an orthonormal basis of real eigenvectors.
  • The Rayleigh quotient lies between the smallest and the largest eigenvalue.

1. Least squares and conditioning

A matrix A \in \mathbb{R}^{m \times p} with more rows than columns, and a vector b \in \mathbb{R}^m, rarely satisfy A x = b. Least squares replaces the equation by the nearest point of the column space. The same A reappears as the Jacobian of a nonlinear model. Its singular values decide whether that linear step is stable.

The normal equations

Definition 1.1 — Least-squares objective

The least-squares objective is f(x) = \frac{1}{2} \|A x - b\|_2^2. A minimizer x_\star is a least-squares solution. Its residual is r = b - A x_\star.

Theorem 1.2 — Normal equations

The vector x_\star minimizes f if and only if A^\top A x_\star = A^\top b. The residual is then orthogonal to every column of A. If those columns are linearly independent, then A^\top A is invertible and the only minimizer is x_\star = (A^\top A)^{-1} A^\top b.

Proof. Expand \|A(x + d) - b\|_2^2. The square splits into \|A x - b\|_2^2, the cross term 2 d^\top A^\top (A x - b), and \|A d\|_2^2.

The last term is nonnegative for every d. The cross term vanishes for every d if and only if A^\top (A x - b) = 0. That identity is A^\top r = 0 with r = b - A x, so r is orthogonal to the columns.

If A^\top A d = 0, then \|A d\|_2^2 = d^\top A^\top A d = 0, hence A d = 0. Independent columns force d = 0. Thus A^\top A is positive definite and the minimizer is unique. ∎

Orthogonality is Pythagoras in the column space. Because r is orthogonal to A x_\star, \|b\|_2^2 = \|A x_\star\|_2^2 + \|r\|_2^2. The residual length is the distance from b to the column space, and no other x makes it shorter.

Example 1.3 — Three equations, two unknowns

Let A = \begin{pmatrix} 1 & 0 \\ 1 & 1 \\ 1 & 2 \end{pmatrix}, \qquad b = \begin{pmatrix} 1 \\ 2 \\ 2 \end{pmatrix}. Then A^\top A = \begin{pmatrix} 3 & 3 \\ 3 & 5 \end{pmatrix}, \qquad A^\top b = \begin{pmatrix} 5 \\ 6 \end{pmatrix}. The determinant of A^\top A is 6, and (A^\top A)^{-1} = \frac{1}{6}\begin{pmatrix} 5 & -3 \\ -3 & 3 \end{pmatrix}. Multiplying by A^\top b gives x_\star = (7/6,\ 1/2).

The residual is r = (-1/6,\ 1/3,\ -1/6). Then \|r\|_2^2 = 1/6 and A^\top r = 0. Pythagoras checks: \|A x_\star\|_2^2 = 53/6 and 53/6 + 1/6 = 9 = \|b\|_2^2.

Singular values

Definition 1.4 — Singular values

Suppose A has full column rank. The singular values \sigma_1 \ge \cdots \ge \sigma_p > 0 are the square roots of the eigenvalues of the symmetric matrix A^\top A. The condition number is \kappa(A) = \sigma_1 / \sigma_p.

Proposition 1.5 — Normal equations square the condition number

The eigenvalues of A^\top A are \sigma_i^2. Therefore \kappa(A^\top A) = \kappa(A)^2.

Proof. Theorem 0.6 applied to the symmetric positive definite matrix A^\top A yields an orthonormal V and the diagonal of squared singular values. The ratio of the extreme eigenvalues is (\sigma_1 / \sigma_p)^2. ∎

Forming A^\top A and calling a dense solver is a clear way to learn Theorem 1.2. It is a poor way to solve a real problem when \kappa(A) is large, because the computed Gram matrix carries \kappa(A)^2. A QR factorization works with A itself and keeps the original condition number. Exercise 5 computes both numbers on Example 1.3. Exercise 6 prints them for a random draw.

Key 1.6 — What to solve

The identity to remember is A^\top r = 0. Invert A^\top A only when p is tiny and \kappa(A) is moderate.

A design with nearly collinear columns makes \sigma_p small, so a small change in b can move x_\star by about \kappa(A) in relative 2-norm, up to the usual factors that compare \|b\| with \|A x_\star\|. The square in Proposition 1.5 is the extra damage you add by forming the normal equations before that sensitivity is felt.

Key takeaways — chapter 1

  • A least-squares residual is orthogonal to the columns of A, and that orthogonality is the normal equation.
  • Full column rank makes A^\top A positive definite and the minimizer unique.
  • The eigenvalues of A^\top A are the squared singular values, so the condition number is squared.
  • Pythagoras splits \|b\|_2^2 into the fitted piece and the squared residual.

2. Convex functions and gradient descent

The quadratic in the introduction is already the model for this chapter. One eigenvalue is 1 and the other is 100, so gradient descent damps the two coordinates at different speeds.

Convexity

Definition 2.1 — Convex function

A function f : \mathbb{R}^p \to \mathbb{R} is convex when, for all x, y and all t \in [0, 1], f\bigl(t x + (1 - t) y\bigr) \le t f(x) + (1 - t) f(y). It is \mu-strongly convex, with \mu > 0, when f(x) - (\mu/2)\|x\|_2^2 is convex.

Proposition 2.2 — First-order characterization

Suppose f is differentiable. Then f is convex if and only if every pair x, y satisfies f(y) \ge f(x) + \langle \nabla f(x),\, y - x \rangle.

Proof. Assume convexity. The difference quotient of f along the segment from x to y is at most f(y) - f(x). Let the step tend to 0. The quotient tends to \langle \nabla f(x), y - x \rangle, which is the inequality.

Conversely, fix t \in (0, 1) and set z = t x + (1 - t) y.

Apply the inequality at z, once toward each endpoint. Multiply one copy by t and the other by 1 - t, then add.

The inner products cancel because t(x - z) + (1 - t)(y - z) = 0. What remains is the definition of convexity.

∎

Exercise 7 checks the quadratic case by an exact expansion.

A safe step

Definition 2.3 — Lipschitz gradient

The gradient of f is L-Lipschitz when every pair x, y satisfies \|\nabla f(x) - \nabla f(y)\|_2 \le L \|x - y\|_2. One then says that f is L-smooth.

On a quadratic (1/2) x^\top H x with symmetric H, the constant L is the largest eigenvalue of H. The constant \mu is the smallest eigenvalue when that eigenvalue is positive.

Theorem 2.4 — Descent lemma and a 1/k rate

Assume f is convex and L-smooth, and let x_\star be a minimizer. The iteration x_{k+1} = x_k - \gamma \nabla f(x_k) with 0 < \gamma \le 1/L satisfies f(x_K) - f(x_\star) \le \frac{\|x_0 - x_\star\|_2^2}{2 \gamma K}.

Proof. Integrate the gradient along the segment from x to y. Subtract \langle \nabla f(x), y - x \rangle and use the Lipschitz bound. The remainder is at most (L/2)\|y - x\|_2^2, so f(y) \le f(x) + \langle \nabla f(x), y - x \rangle + \frac{L}{2}\|y - x\|_2^2.

Set y = x - \gamma \nabla f(x). The inner product contributes -\gamma \|\nabla f(x)\|_2^2. For \gamma \le 1/L the quadratic penalty is at most half of that decrease, and f(x - \gamma \nabla f(x)) \le f(x) - \frac{\gamma}{2}\|\nabla f(x)\|_2^2. The values f(x_k) therefore decrease.

Convexity gives the tangent lower bound \langle \nabla f(x_k), x_k - x_\star \rangle \ge f(x_k) - f(x_\star).

Expand the squared distance from x_{k+1} to x_\star. Replace \|\nabla f(x_k)\|_2^2 by the decrease just proved. The cross terms simplify to \|x_{k+1} - x_\star\|_2^2 \le \|x_k - x_\star\|_2^2 - 2\gamma \bigl(f(x_{k+1}) - f(x_\star)\bigr).

Sum from k = 0 to K - 1. The distances telescope.

Because the values f(x_k) decrease, each gap f(x_{k+1}) - f(x_\star) is at least the final gap f(x_K) - f(x_\star). Divide by 2\gamma K.

∎

The step 1/L is safe for monotone decrease. It is not the largest step that can still converge.

On a quadratic, the coordinate of eigenvalue \lambda is multiplied by 1 - \gamma \lambda at every iteration. That factor stays strictly inside (-1, 1) only when 0 < \gamma < 2/L.

At the endpoint \gamma = 2/L the steepest coordinate flips sign and does not tend to 0. Theorem 2.4 uses the smaller range because the proof needs f to decrease.

Example 2.5 — Two speeds

Let f(x, y) = (1/2)(x^2 + 100 y^2). The gradient is (x,\ 100 y), so L = 100 and \mu = 1. The step \gamma = 1/L = 0.01 is the step of Theorem 2.4. Start at (1,\ 1).

One update sends the state to (0.99,\ 0). The steep coordinate is finished. Each later update multiplies the flat coordinate by 0.99, which is 1 - \mu/L.

import numpy
z = numpy.array([1.0, 1.0])
for _ in range(100):
    g = numpy.array([z[0], 100.0 * z[1]])
    z = z - 0.01 * g
print(f"{z[0]:.4f}")
print(f"{z[1]:.4f}")
print(f"{0.5 * (z[0] ** 2 + 100.0 * z[1] ** 2):.4f}")

The three printed lines are 0.3660, 0.0000 and 0.0670. Theorem 2.4 with K = 100 and \|x_0 - x_\star\|_2^2 = 2 only promises that the value is at most 1. The bound holds, and it is loose, because this f is strongly convex and the theorem used only convexity. Exercise 8 computes the exact one-dimensional contraction.

Key 2.6 — The update

The iteration to remember is x \leftarrow x - \gamma \nabla f(x) with 0 < \gamma \le 1/L when a Lipschitz constant of the gradient is known.

Key takeaways — chapter 2

  • A differentiable function is convex exactly when its graph lies above every tangent.
  • An L-Lipschitz gradient gives the descent lemma and forbids steps larger than 1/L in Theorem 2.4.
  • Convexity plus that step yields an optimality gap of order 1/k.
  • On a diagonal quadratic the coordinates shrink at rates 1 - \gamma \lambda_i, so the condition number is visible in the iteration.

3. Constraints, multipliers and duality

A multiplier is the price of a constraint that plain gradient descent does not see, such as A x = b. The rule below is necessary under a rank condition, and it is sufficient when the problem is convex.

Equalities

Definition 3.1 — Lagrangian

For an objective f and a constraint map h with m components, the Lagrangian of minimizing f(x) subject to h(x) = 0 is \mathcal{L}(x, \lambda) = f(x) + \lambda^\top h(x), \qquad \lambda \in \mathbb{R}^m.

Theorem 3.2 — Lagrange multipliers

Let x_\star be a local minimizer of f on the set where h(x) = 0.

Assume f and h are continuously differentiable and the Jacobian at x_\star has full row rank. Then some multiplier \lambda_\star satisfies \nabla f(x_\star) + Dh(x_\star)^\top \lambda_\star = 0, \qquad h(x_\star) = 0.

Proof. Full row rank means the columns of Dh(x_\star)^\top span every direction orthogonal to the tangent space \{d : Dh(x_\star)\, d = 0\}.

If \nabla f(x_\star) had a nonzero component in that tangent space, a feasible curve through x_\star would decrease f at first order. A local minimum forbids that component.

Hence \nabla f(x_\star) lies in the column span of Dh(x_\star)^\top. The implicit-function theorem turns a tangent vector into a genuine curve on the constraint set. The rank hypothesis is what makes that curve exist. ∎

Proposition 3.3 — Minimum-norm solution

Let A \in \mathbb{R}^{m \times p} have full row rank, and let b \in \mathbb{R}^m. The unique minimizer of (1/2)\|x\|_2^2 subject to A x = b is x_\star = A^\top (A A^\top)^{-1} b.

Proof. Apply Theorem 3.2 to f(x) = (1/2)\|x\|_2^2 and h(x) = A x - b. Stationarity reads x_\star + A^\top \lambda = 0, and feasibility reads A x_\star = b.

Substitute x_\star = -A^\top \lambda into the linear equation. Then -A A^\top \lambda = b. Full row rank makes A A^\top invertible, so \lambda and x_\star are determined. The Hessian of f is the identity, so this critical point is the unique global minimizer. ∎

Inequalities

Definition 3.4 — Inequality constraints

Let g map into \mathbb{R}^q. Minimize f(x) subject to the equalities h(x) = 0 and the inequalities g(x) \le 0.

A multiplier \mu is dual-feasible when \mu \ge 0. Complementary slackness means \mu_i g_i(x) = 0 for every index i.

Proposition 3.5 — Convex KKT conditions are sufficient

Assume f and the components of g are convex and differentiable, and assume h is affine. Suppose x_\star is feasible and some \lambda and some \mu \ge 0 satisfy complementary slackness together with \nabla f(x_\star) + Dh(x_\star)^\top \lambda + Dg(x_\star)^\top \mu = 0. Then x_\star is a global minimizer.

Proof. Stationarity says that x_\star minimizes the Lagrangian over \mathbb{R}^p. The Lagrangian is convex, and its gradient vanishes at x_\star.

Take any feasible x. Then h(x) = 0 and \mu^\top g(x) \le 0. Complementary slackness gives \mu^\top g(x_\star) = 0.

The Lagrangian at x is at most f(x). It is at least the Lagrangian at x_\star, which equals f(x_\star). Hence f(x) \ge f(x_\star).

∎

Example 3.6 — Projection onto a line

Minimize (x - 2)^2 + (y - 1)^2 subject to x + y = 1. This is the Euclidean projection of the point (2,\ 1) onto the line.

Stationarity gives 2(x - 2) + \lambda = 0 and 2(y - 1) + \lambda = 0.

So x - y = 1. Together with x + y = 1 one gets x = 1, y = 0 and \lambda = 2.

The same point is the general projection formula. With a = (1,\ 1) and p = (2,\ 1), p - \frac{(a^\top p - 1)\, a}{\|a\|_2^2} = (1,\ 0). The distance from (2,\ 1) to (1,\ 0) is \sqrt{2}. The objective is convex and the constraint is affine, so Proposition 3.5 certifies a global minimum. Here there is no inequality, and \mu is absent.

Note 3.7 — Slater’s condition

For a feasible point and a dual-feasible multiplier, the Lagrangian is a lower bound on the optimal value. The gap is zero in Proposition 3.3. A standard sufficient condition for a zero gap on a convex inequality problem asks for a feasible point at which every inequality is strict. That hypothesis is called Slater’s condition. It fails when the inequality cannot be made strict. Exercise 10 computes a gap of 1 on such a problem. Boyd and Vandenberghe (2004) develop the criterion.

Key 3.8 — Four lines

Stationarity, primal feasibility, dual feasibility \mu \ge 0, and complementary slackness are the KKT lines. On a convex problem they certify a global minimizer.

Key takeaways — chapter 3

  • At a constrained local minimum with a full-rank Jacobian, the objective gradient is a combination of the constraint gradients.
  • The minimum-norm solution of a full-rank linear equation is A^\top (A A^\top)^{-1} b.
  • On a convex problem, the KKT lines are sufficient for a global minimum.
  • Without a strict feasible inequality, a convex problem can still have a positive duality gap.

4. Research directions and open problems

The in-class bound of Theorem 2.4 is of order L R^2 / k, where R is the distance from the start to a minimizer. Work by Nesterov (1983) produces a first-order method whose gap on a convex L-smooth objective satisfies f(x_k) - f_\star \le \frac{4 L \|y_0 - x_\star\|_2^2}{(k + 2)^2}. The sequence of objective values need not decrease at every iteration. The 1983 note already states that the order 1/k^2 cannot be improved for this class. Nemirovski and Yudin (1983) develop the matching complexity theory. Nesterov (2004) is the textbook proof a reader can work in the four hours attached to this chapter.

Polyak (1964) adds a momentum term to gradient descent. On a quadratic whose condition number is \kappa, a tuned momentum method replaces the plain contraction (\kappa - 1)/(\kappa + 1) by (\sqrt{\kappa} - 1)/(\sqrt{\kappa} + 1). The square root is the same structural gain that acceleration later obtains beyond quadratics. The price is a method that can increase f on some steps, which Theorem 2.4 refused to do.

Smooth equalities are not the constraints that appear in sparse regression. Beck and Teboulle (2009) accelerate the proximal-gradient method for an objective f + g with f smooth and g convex, possibly nonsmooth. The proximal map of a multiple of the 1-norm is soft-thresholding. This page stops at smooth penalties. That map is the natural next algorithm, and FISTA is its accelerated form.

Stochastic gradients replace \nabla f(x_k) by an unbiased estimate. Robbins and Monro (1951) prove convergence in probability for a root-finding recursion whose steps \gamma_k > 0 satisfy \sum_k \gamma_k = \infty, \qquad \sum_k \gamma_k^2 < \infty. A constant step does not meet the second requirement. It can converge to a neighbourhood whose radius tracks the noise, and then it oscillates. Bottou, Curtis and Nocedal (2018) survey what these hypotheses become for a finite-sum risk in machine learning, including variance reduction.

Nonconvex training adds saddles. Jin, Ge, Netrapalli, Kakade and Jordan (2017) show that gradient descent with occasional random perturbations reaches a point with small gradient and no large negative Hessian eigenvalue, in polynomial time, when the gradient and the Hessian are Lipschitz. The theorem injects noise. It does not say that one silent run with a fixed step will leave every saddle.

Adaptive steps are the other open edge. Kingma and Ba (2015) propose Adam. Reddi, Kale and Kumar (2018) give a convex online problem on which Adam fails to converge, and they propose AMSGrad as a repair. Adam remains a default in deep learning. Explaining that practical behaviour, or matching it with a method that keeps a convex guarantee, is open.

Implicit bias is a property of the path, not of the critical-point equations. Soudry, Hoffer, Nacson, Gunasekar and Srebro (2018) prove that on linearly separable data, gradient descent on a smooth loss with an exponential tail drives a homogeneous linear predictor to the hard-margin direction. The convergence in direction is only logarithmic in the loss. The paper also treats one weight layer in a restricted network. A general deep network lies outside that theorem.

Key takeaways — chapter 4

  • Acceleration improves the convex smooth rate from 1/k to 1/k^2, and the 1983 constant is 4L over (k+2)^2.
  • Proximal maps, stochastic steps and saddle escape sit outside Theorems 2.4 and 3.2.
  • Adam can fail on a convex problem. Its success in deep learning is not settled by the AMSGrad repair.
  • On separable linear data, gradient descent has a max-margin bias. The deep-network case is only partly mapped.

Exercises

Levels follow the session plan. One star applies a chapter. Two stars combine two facts or finish a short proof. Three stars add a certification argument or a gap.

  1. ★ Three norms of one vector. Let v = (3, -4). Compute \|v\|_1, \|v\|_2 and \|v\|_\infty. Check the order \|v\|_\infty \le \|v\|_2 \le \|v\|_1, and check \|v\|_1 \le \sqrt{2}\,\|v\|_2.

    Solution. The three values are 7, 5 and 4. The order reads 4 \le 5 \le 7.

    Also \sqrt{2} \cdot 5 > 7, so the comparison of the 1-norm with \sqrt{n} times the Euclidean norm holds on this vector. Equality in \|v\|_2 = \|v\|_1 would need a vector with only one nonzero coordinate. This v is not of that form.

  2. ★ Largest eigenvalue of a random symmetric matrix. Draw a 4 by 4 matrix with numpy.random.default_rng(0), symmetrize it by averaging it with its transpose, and compute the largest eigenvalue.

    import numpy
rng = numpy.random.default_rng(0)
G = rng.normal(size=(4, 4))
A = 0.5 * (G + G.T)
lam = numpy.linalg.eigvalsh(A)
print(f"{lam.max():.6f}")

    Solution. The fence prints 1.216415. That number is the largest eigenvalue of A. Theorem 0.6 says it is real because A was forced to be symmetric. The Rayleigh quotient of a matching unit eigenvector equals this printed value, and every other unit vector yields a smaller quadratic form.

  3. ★ Spectral factorization of a 2 by 2 matrix. For the matrix of Example 0.7, compute the characteristic polynomial, the eigenvalues, and a pair of unit eigenvectors. Check e_1^\top A e_1 against the Rayleigh bound.

    Solution. The polynomial is \lambda^2 - 4\lambda + 3 = (\lambda - 1)(\lambda - 3). The eigenvalues are 1 and 3.

    Unit eigenvectors are (1, -1)/\sqrt{2} for eigenvalue 1 and (1, 1)/\sqrt{2} for eigenvalue 3.

    Then e_1^\top A e_1 = 2, which lies between 1 and 3. The code in ch. 0 rebuilds A and prints a residual of 4.4e-16.

  4. ★ Normal equations on three rows. Solve Example 1.3 from A^\top A and A^\top b. Report x_\star, the residual, and \|r\|_2^2.

    Solution. As in the example, A^\top A has rows (3, 3) and (3, 5), and A^\top b = (5, 6). The inverse times (5, 6) equals (7/6,\ 1/2).

    The residual is (-1/6,\ 1/3,\ -1/6). Its squared Euclidean norm is 1/6, and A^\top r = 0. The Pythagorean check is 53/6 + 1/6 = 9.

  5. ★★ Condition number of a Gram matrix. For the A of Example 1.3, compute the eigenvalues of A^\top A exactly and relate their ratio to \kappa(A)^2.

    Solution. The characteristic polynomial of A^\top A is \lambda^2 - 8\lambda + 6. The roots are 4 + \sqrt{10} and 4 - \sqrt{10}.

    Their ratio equals \kappa(A)^2 by Proposition 1.5, because those roots are the squared singular values. The smaller root is positive, which matches full column rank and the unique minimizer of Theorem 1.2.

  6. ★★ A random least-squares residual. With numpy.random.default_rng(0), draw a 12 by 3 matrix and a length-12 right-hand side from the standard normal distribution. Print the sum of squared residuals, the condition number of A, its square, and the rank.

    import numpy
rng = numpy.random.default_rng(0)
A = rng.normal(size=(12, 3))
b = rng.normal(size=12)
x, residuals, rank, s = numpy.linalg.lstsq(A, b, rcond=None)
cond = float(numpy.linalg.cond(A))
print(f"{float(residuals[0]):.6f}")
print(f"{cond:.6f}")
print(f"{cond ** 2:.6f}")
print(int(rank))

    Solution. The fence prints 15.253706, then 3.137250, then 9.842339, then 3. The first line is \|A x_\star - b\|_2^2 from lstsq, not the residual norm itself.

    The rank is 3, so Theorem 1.2 gives a unique minimizer. The printed condition number is moderate. Its square, 9.842339, is \kappa(A^\top A) by Proposition 1.5. Forming the normal equations does not square a large number on this draw.

  7. ★★ Convexity of a quadratic. Let H be symmetric and let f(x) = (1/2) x^\top H x + c^\top x. Prove that f is convex if and only if H is positive semidefinite.

    Solution. The gradient is \nabla f(x) = H x + c. Expand the first-order gap. For every x and y, f(y) - f(x) - \langle \nabla f(x), y - x \rangle = \frac{1}{2}(y - x)^\top H (y - x).

    The left side is nonnegative for all pairs if and only if the right side is. That is the Rayleigh condition for H, so H is positive semidefinite. Proposition 2.2 then gives convexity of f. If some direction has a negative curvature, the right side is negative along that step and the tangent test fails.

  8. ★★ Exact contraction on a line. Let f(t) = (\beta/2) t^2 with \beta > 0. Write the gradient iteration with step \gamma.

    Use \beta = 4, t_0 = 1 and \gamma = 1/8. Compute t_4 and f(t_4), and compare the gap with Theorem 2.4.

    Solution. Here f'(t) = \beta t, so t_{k+1} = (1 - \gamma \beta) t_k and t_k = (1 - \gamma \beta)^k t_0. The error tends to 0 if and only if |1 - \gamma \beta| < 1, that is 0 < \gamma < 2/\beta.

    With the numbers above, the factor is 1/2 and t_4 = 1/16. Then f(t_4) = 1/128. Theorem 2.4 bounds the gap by \|t_0\|_2^2 / (2 \gamma K) = 1. The true gap is far smaller. The step \gamma = 1/\beta finishes the problem in one iteration, which the pure convex bound does not see.

  9. ★★★ Projection onto the nonnegative orthant. Minimize (1/2)\|x - z\|_2^2 over x \ge 0. Derive the minimizer from the KKT lines, specialize to z = (2, -1), and explain why a vanishing derivative is not enough without convexity.

    Solution. Write the inequalities as g_i(x) = -x_i. Stationarity gives x - z = \mu with \mu \ge 0, together with x \ge 0 and \mu_i x_i = 0.

    If z_i \ge 0, take x_i = z_i and \mu_i = 0. If z_i < 0, take x_i = 0 and \mu_i = -z_i.

    Thus x_i = \max(z_i, 0). For z = (2, -1) the minimizer is x = (2, 0), and the distance is 1.

    Proposition 3.5 applies. The objective is convex and the constraints are affine.

    Convexity is necessary for that certificate. The derivative of t \mapsto -t^2 vanishes at 0, but 0 is a maximizer. Stationarity alone does not select a minimum.

  10. ★★★ A zero gap and a gap of one. (a) Minimize (1/2)(x^2 + y^2) subject to x + y = 2. Compute the primal value and the dual function. (b) Minimize e^{-x} subject to x^2 / y \le 0 with y > 0. Show that the duality gap equals 1, and say why Slater’s condition fails.

    Solution. For (a), Proposition 3.3 gives (x, y) = (1, 1) and primal value 1. The Lagrangian is (1/2)(x^2 + y^2) + \lambda(x + y - 2). Its minimum over (x, y) is the dual function g(\lambda) = -\lambda^2 - 2\lambda, whose maximum is g(-1) = 1. The gap is zero.

    For (b), the constraint x^2 / y \le 0 with y > 0 forces x = 0. The optimal value is 1.

    For any \lambda \ge 0 and any \varepsilon > 0, choose x so that e^{-x} < \varepsilon, then choose y > \lambda x^2 / \varepsilon.

    The Lagrangian is then below 2\varepsilon. The dual function is identically 0, and the gap is 1.

    Slater’s condition asks for a point with x^2 / y < 0 and y > 0. No such point exists, so the strict-feasibility route to a zero gap does not apply. The problem is still convex on y > 0. Convexity alone did not force the gap to vanish.
