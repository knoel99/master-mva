This is a framing page, not a course: the module is a tutored project. Students read a scientific article in detail, implement the method, publish a complete scientific report with its source code, and build an online demonstrator in the IPOL journal system.

Each year the MVA lecturers propose articles that deserve a reproducible edition; projects may be co-supervised by researchers of Centre Borelli or other research centres.

What the module asks

  • Write a reproducible article: introduction with the main ideas, method and architecture, data, training and inference for neural methods, experiments, limitations and conclusion.
  • Match the code to the pseudo-code, at the right level of mathematical and algorithmic detail.
  • Review another group’s work, which puts every student in both the author and the reviewer role.

The short introductory sessions cover writing (structure, style, analysis of good and bad articles), tools (online execution and dissemination platforms, peer-reviewed journals, git and GitHub or GitLab, LaTeX and Overleaf, agile team organisation), and coding practice (seeded pseudo-random generators, choice of libraries, assertions of invariants, granularity of functions, documentation, and what reproducibility means for a neural network: algorithm, architecture, weights and data).

How to prepare

  • Follow Fundamentals of Reproducible Research and Free Software in semester 1, or read its page: version control, environments, testing, licences and the IPOL model.
  • Pick an article in a field you master: many course pages of these notes end with a paper-study project that can grow into an IPOL edition — for example Image Denoising, Sub-Pixel Image Processing or Detection Theory.
  • Plan the demo early: an online demonstrator constrains the run time and the input formats of the code.

Deliverables and assessment

  • A complete IPOL pre-print per group: the article, the source code and an online demo.
  • An evaluation report on the project of another group.
  • Weights: the final reproducible project 80 %, the intermediate practical work 20 %.

These are the official rules from master-mva.com; this page adds no assessment of its own.
